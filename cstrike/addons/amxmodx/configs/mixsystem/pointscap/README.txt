PointScap Map-Specific Zones Directory
======================================

This directory contains map-specific zone configurations for PointScap mode.

File naming: <map_name>.ini
Example: de_dust2.ini, de_inferno.ini, de_nuke.ini

Each map can have its own zone configuration.
If no map-specific config exists, the default hns-pointscap-zones.ini will be used.

Use /muin command in-game to measure and save zones for the current map.
