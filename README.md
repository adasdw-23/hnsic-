# HNSIC beta2.0 更新说明

## 版本说明

`beta2.0` 主要是对比赛服核心功能做了一轮集中修复和整理，重点处理了权限系统、聊天前缀、点位积分、管理员菜单、皮肤系统，以及皮肤账号绑定等问题。

这次更新的目标不是单独新增某一个功能，而是把整套插件链路修顺，让实际开服使用时更稳定、更清晰。

## 本次更新内容

### 1. 权限与聊天前缀修复

- 修复管理员、辅助等聊天前缀不显示的问题
- 修复权限迁移时旧数据可能识别错误的问题
- 增加权限存档版本标记，避免后续权限编号错乱
- 统一权限显示名称：
  - 服主
  - 管理员
  - VIP
  - 辅助
- 修复 `/fuzhu` 错误触发服主认证的问题，改为真正的辅助认证
- 取消与聊天前缀系统重复改写消息的冲突逻辑

### 2. 官方管理员菜单修复

- 修复服主和管理员无法打开官方 `AMX Mod X` 管理员菜单的问题
- 为服主/管理员补上 `ADMIN_MENU` 权限位
- 优化 `/menu` 入口逻辑：
  - 管理员优先进入官方管理员菜单
  - 普通玩家继续使用原玩家菜单
- 服务器语言调整为中文
- 补充官方管理员菜单相关语言文件，修复部分菜单未中文化的问题

### 3. 点位积分系统修复

- 缩小默认点位判定框，避免判定范围过大
- `3/4/5人点` 使用更合理的默认判定范围
- 编辑器录点改为更精确的小边距模式
- 占点检测改为包围盒判定，不再只看玩家中心点
- 正式接入 `stay_time`，需要停留足够时间才会判定成功
- 补充点位触发记录，完善占点类型状态
- 修复 `Vampire` 模式下点位相关任务清理不完整的问题

### 4. 皮肤系统整理

- 维持默认皮肤自动发放逻辑
- 额外皮肤继续按单个发放逻辑处理
- 保留未解锁皮肤显示，方便玩家查看哪些皮肤未获得
- 修复管理菜单与皮肤菜单的部分入口冲突问题
- 整理皮肤系统结构，便于后续继续扩展

### 5. 内测账号系统

新增内测账号注册/登录能力，用于将皮肤数据从单纯的 `SteamID / IP / 名字` 识别，提升到更稳定的账号识别模式。

支持命令：

- `/reg <内测名> <密码>`
- `/login <内测名> <密码>`
- `/logout`
- `/account`

更新后逻辑：

- 已登录内测账号时，皮肤优先绑定到该账号
- 未登录时，继续兼容旧识别方式
- 管理员皮肤与普通皮肤存档共用同一套账号身份逻辑

这样可以减少盗版环境下因改名、换名字、冒名等导致的皮肤数据混乱问题。

### 6. 其他修复

- 修复 AI 分组相关状态恢复与断线重连问题
- 修复 Watcher 与权限 flags 互相覆盖的问题
- 修复 HUD 显示冲突
- 修复地图切换与暂停执行细节问题
- 修复 TestBots 对真人误判的风险
- 重新整理并编译核心插件产物
